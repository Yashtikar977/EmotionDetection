# Emotion Detector

## Project Description

Emotion Detector is an AI-based web application that detects emotions
from user-provided text using IBM Watson NLP.

## Technologies Used

- Python
- IBM Watson NLP
- Flask
- Unit Testing
- Pylint

## Project Tasks

1. Emotion detection using Watson NLP
2. Output formatting
3. Python package creation
4. Unit testing
5. Flask web deployment
6. Error handling
7. Static code analysis
